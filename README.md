# QLD 매매전략 대시보드

QLD 200일선 + QQQ RSI 규칙으로 매일 매매 상태를 계산해 보여주는 웹 위젯입니다.
GitHub Pages로 호스팅되고, GitHub Actions가 매 거래일 장 마감 후 Yahoo Finance에서 확정 종가를 받아 `data/prices.json`을 갱신합니다. 서버나 Cloudflare 없이 GitHub만으로 동작합니다.

## 구조

```
index.html                     화면 + 전략 계산 (브라우저에서 실행)
data/prices.json               QLD·QQQ 일봉 종가 (Actions가 자동 갱신)
scripts/fetch-prices.mjs       Yahoo Finance에서 종가 받아오는 스크립트
.github/workflows/update.yml   매일 데이터 갱신 + Pages 배포
```

## 설정 방법

1. GitHub에서 새 저장소를 만들고(Public 권장 — 무료 계정은 Public이어야 Pages 사용 가능) 이 폴더의 파일을 모두 올립니다. `.github` 폴더도 꼭 포함하세요.
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Settings → Actions → General → Workflow permissions** 를 **Read and write permissions** 로 바꿉니다. (데이터 커밋에 필요)
4. **Actions** 탭 → *Update prices & deploy* → **Run workflow** 로 한 번 실행합니다.
5. 끝나면 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

이후로는 평일 미국 장 마감 후(한국시간 다음날 아침 6~7시경) 자동으로 갱신됩니다.

## 처음 설정 (한 번만)

페이지 오른쪽 **기본 설정**에 아래 4가지를 넣고 저장합니다.

- 현재(시작일 기준) QLD 비중 %
- 총 운용금액 ($) — 매수·매도 금액 계산 기준 (예: $10,000 → 주간 2.5%p = $250)
- 전략 시작일 — 비워 두면 가장 최근 종가일
- TURBO 가용한도 — 0 / 10 / 20 / 30% (운용금액 대비, TQQQ 투입액)

## 매일 쓰는 법

아침에 위젯만 보면 됩니다. 맨 위에 할 일이 하나 나옵니다:
매수 · 대기 · 매수중지 · 매도 · 전량매도 · 재진입 · TURBO

주간 매수 신호(예: `2.5%p 매수 · 이번 주 매수금액 $250`)가 뜨면 증권사에서 산 뒤
**✓ 이번 주 2.5%p 매수 완료 · $250** 버튼을 누르세요. 기록 비중이 70% → 72.5%로 올라가고 그 주는 완료로 넘어갑니다.
잘못 눌렀으면 "매수 완료 취소"로 되돌릴 수 있습니다.

전량매도·재진입·RSI ±10%p·TURBO 신호는 종가로 자동 판정되므로 따로 누를 필요가 없습니다 (신호대로 실행했다고 보고 비중을 반영).

## 참고

- 설정과 주간 매수 완료 기록은 브라우저에 저장됩니다. 기기(브라우저)마다 따로 저장되니 한 기기에서 쓰는 걸 권장합니다.
- 원칙에 숫자가 없는 부분(재진입 비중 50%, 3번째 과열 −20%p, Lock 조건, BOOST 기준 200MA +10%·RSI 55~75 등)은 페이지의 **세부 규칙값**에서 바꿀 수 있습니다.
- Yahoo Finance가 일시적으로 막히면 그날은 기존 데이터로 배포되고 다음 실행 때 다시 받아옵니다.
- GitHub은 Public 저장소에 60일간 활동이 없으면 예약 실행을 멈춥니다. 자동 데이터 커밋은 활동으로 안 쳐질 수 있으니, 갱신이 멈췄다면 Actions 탭에서 워크플로를 다시 켜 주세요. 가끔 직접 커밋하면 예방됩니다.
- 투자 판단의 책임은 본인에게 있습니다. 이 도구는 규칙을 기계적으로 계산할 뿐입니다.
